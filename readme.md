# SpaceGame: Ядро и IoC-контейнер

Ветка `feat/ioc` содержит контракты и потокобезопасный IoC-контейнер. 

1. Все зависимости и объекты создаются исключительно через стратегии внутри IoC-контейнера.
2. Логика игры (движение, повороты, выстрелы) реализуется через классы, реализующие интерфейс `ICommand`.
3. Каждая игра (матч) выполняется в своей собственной области видимости (`IScope`), что позволяет гибко настраивать правила и изолировать данные разных матчей в многопоточной среде.


## Что реализовано 

### 1. Базовые абстракции 
* `ICommand` - единый интерфейс для всех исполняемых действий (имеет единственный метод `Execute()`).
* `IGameItem` - универсальный контракт игрового объекта. Состояние объекта хранится в виде словаря свойств и доступно через методы `GetProperty(string key)` и `SetProperty(string key, object value)`.

### 2. Потокобезопасный IoC-контейнер (`IoC.cs`)
Точка входа для разрешения всех зависимостей. Предоставляет статический метод `IoC.Resolve<T>(string key, params object[] args)`.

### 3. Области видимости (`ScopeStructures.cs`)
Реализована иерархическая система областей видимости (`IScope`). Текущий Scope привязан к потоку через `ThreadLocal`, что гарантирует потокобезопасность при параллельном выполнении нескольких игр.
